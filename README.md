# Taller PHP con POO

Conjunto de siete aplicaciones web desarrolladas con HTML, CSS, PHP y programación orientada a objetos. La página principal contiene un menú donde redirige a cada aplicación.

## Aplicaciones

1. **Acrónimo:** convierte una frase en su acrónimo.
2. **Fibonacci / Factorial:** genera la serie según la operación elegida.
3. **Promedio, mediana y moda:** calcula estos valores para una serie de números reales.
4. **Conjuntos:** calcula la unión, la intersección y las diferencias A − B y B − A.
5. **Decimal a binario:** convierte un número entero a binario.
6. **Árbol binario:** construye un árbol a partir de dos o más recorridos (preorden, inorden y postorden).
7. **Calculadora:** realiza las operaciones básicas y guarda un historial que se puede borrar.
